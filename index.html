sileo-slint

A physics-based toast component for Slint, with a Rust API. A toast is a small pill. When it has more to say, a body grows out of it with a spring. Port of Sileo for React.

GitHub crates.io docs.rs

Playground

This is the real component, compiled to WebAssembly. Hover a toast to expand it, swipe it up or down to dismiss it.

Install

Needs Slint 1.18 or newer. Your code and your build script both use the crate.

cargo add slint sileo-slint
cargo add --build slint-build sileo-slint
build.rs
fn main() {
    let config = slint_build::CompilerConfiguration::new()
        .with_library_paths(sileo_slint::library_paths());
    slint_build::compile_with_config("ui/app.slint", config).unwrap();
}
ui/app.slint
import { Sileo, SileoItem, SileoKind, SileoPosition, SileoToast, Toaster } from "@sileo";
export { Sileo, SileoItem, SileoKind, SileoPosition, SileoToast }

export component App inherits Window {
    // your content first, the Toaster last so it is drawn on top
    Toaster { }
}
src/main.rs
slint::include_modules!();

fn main() -> Result<(), slint::PlatformError> {
    let ui = App::new()?;
    sileo_slint::init!(ui);
    ui.global::<Sileo>().invoke_success("Saved".into(), "Your changes are stored.".into());
    ui.run()
}
